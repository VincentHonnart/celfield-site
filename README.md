# celfield.com — site vitrine

Page unique, autonome (`public/index.html`, images et polices embarquées).
Publiée par Netlify depuis ce dépôt : un `git push` la met en ligne.

- **Formulaire de démo** : Netlify Forms, formulaire `demo`. Les demandes se lisent dans
  Netlify (Forms) et sont notifiées par email.
- **contact@celfield.com** : Cloudflare Email Routing, redirigé vers la boîte de Vincent.
- **Ne jamais** mettre ce site dans le dépôt `celfield-crm` : celui-ci publie sa racine
  sur les sites clients.
